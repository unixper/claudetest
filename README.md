# claudetest

Claude Code（クラウドセッション）と GitHub を試すための実験用リポジトリです。

## 用語メモ

| 用語 | ざっくりした意味 |
| --- | --- |
| リポジトリ | プロジェクトのファイルと、その変更履歴をまとめて保管する「箱」 |
| コミット | 「この時点のファイルの状態」を履歴に1件記録すること（セーブポイント） |
| ブランチ | 本流（main）から枝分かれした作業用の線。本流を汚さずに試せる |
| プッシュ | 手元（今回はクラウドのコンテナ）で作ったコミットを GitHub に送ること |
| プルリクエスト（PR） | 「このブランチの変更を main に取り込んでください」という提案 |
| マージ | ブランチの変更を main に取り込むこと |
